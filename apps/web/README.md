# 💻 Mpus Web Catalog & Admin Dashboard

Aplikasi Web **Next.js 14 + Tailwind CSS** untuk katalog publik Mpus (Market Kampus) yang ramah SEO dan panel admin verifikasi.

---

## 🚀 Fitur Utama
1. **Public Web Catalog (SEO Friendly)**: Membuka link sharing barang langsung dari browser tanpa wajib install aplikasi.
2. **Direct WhatsApp Link**: Pembeli web bisa langsung chat penjual via nomor WhatsApp terverifikasi.
3. **Admin Verification Panel**: Dashboard untuk admin kampus memverifikasi KTM dan memoderasi listing produk.

---

## 🛠️ Menjalankan Lokal
```bash
npm install
npm run dev
```
Buka `http://localhost:3000`.
